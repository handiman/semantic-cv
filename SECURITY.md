# Security Policy

## Supported versions

Only the latest released version of `semantic-cv` on [npm](https://www.npmjs.com/package/semantic-cv) receives
security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately in one of these ways:

- Use GitHub's [private vulnerability reporting](https://github.com/handiman/semantic-cv/security/advisories/new).
- Email [security@semantic.cv](mailto:security@semantic.cv).

Include what you found, the steps to reproduce it and the version affected.

## What to expect

- We acknowledge your report within 7 days.
- We keep you updated while we investigate and aim to have a fix or a mitigation within 90 days.
- We disclose the vulnerability once a fix is released, and credit you if you wish.

## Scope

This policy covers the `semantic-cv` CLI and the [semantic-cv-core](https://github.com/handiman/semantic-cv-core) and
[semantic-cv-themes](https://github.com/handiman/semantic-cv-themes) repositories it includes as submodules. Each of
them carries a copy of this policy.
